| --- | --- |
| [Chapter 12 学習ノート](docs/chapter12-notes.md) | 章全体の理解。コンセプト生成の4ステップ、各節の解説、用語・図表、理解確認12問、実務用ワークシート |
| [Chapter 12 輪読発表レジュメ](docs/chapter12-reading-group.md) | 発表30分＋議論15分。画面共有する要点、折りたたみ式の発表者メモ、再結合を体験する演習、想定質問。10分版の進め方も掲載 |

まず学習ノートの[概要](docs/chapter12-notes.md#overview)と[4ステップ](docs/chapter12-notes.md#four-steps)で章の筋をつかみ、各節へ進んでください。復習には[理解確認](docs/chapter12-notes.md#questions)、発表準備にはレジュメの発表者メモを使えます。

本文は逐語訳ではなく、提供画像に基づく要約・再構成です。独自の説明は「補足」「解釈」「演習」として区別しています。自動車の性能値・市場状況・将来予測は原著当時の説明であり、現在の状況を調査した資料ではありません。

図表は原資料から切り出した画像を本文に貼り込み、日本語の説明を添えています。原図のキャプション・出典表記を含め、元の解像度で保存しました。画像を押すと切り出し画像を開けます。Markdownを別の場所へ移す場合は、`docs/assets/chapter12/`も同じ相対位置に置いてください。

発表者メモと理解確認の解答は、HTMLの`details`に対応したMarkdownプレビューで開閉できます。
